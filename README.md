> [!NOTE]
> PureKFD is an exploit based Jailed Package Manager, supporting iOS versions 17.0 through 26.0.1/27.0b4 using SparseRestore, KFD, MDC, DarkSword, CleanSword, bad_querty, bookrestore and more. PureKFD allows users to customize their experience through a user-friendly interface, utilizing community-developed tweaks available from the community’s repositories.

## Getting Started

1. **Compatibility:** Ensure your iOS device is running an iOS version 17.0 through 26.0.1/27.0b4.
3. **Installation:** Download PureKFD from the [github releases](https://github.com/PureKFD/PureKFD/releases/latest) for the latest release
4. **Customize:** Explore the vast array of tweaks, personalize your iOS experience, and make your device truly yours.

## Getting Started With Exploits

> [!WARNING]
> please ensure to NOT sign PureKFD with a cert that is not specifically for PureKFD (for example, sideloading with a wildcard developer cert or enterprise cert)
1. in purekfd settings switch exploit to the exploit you want to use or for your version
2. get [LocalDevVPN](https://apps.apple.com/us/app/localdevvpn/id6755608044) and import the pairing file from SideStore or [StikPair](https://github.com/StikDebug/StikPair)
5. go into purekfd and apply your tweaks!

## Building

1. install theos and ensure its in ~/.zshrc
2. clone this repo recursively
3. open in xcode
4. build purekfd
